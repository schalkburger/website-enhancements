# Bitbucket Enhanced

Various enhancements for Bitbucket.

## Features

- Auto-reloads a PR when Bitbucket shows a "reload/refresh" banner for stale content
- Prefixes the tab title with the PR number (`#1917: ...`)
- Click the source branch name (PR page or branch compare page) to copy it to the clipboard
- Click a comment's "commented on `<file>`" link to copy a permalink to that comment
- Click the `#<id>` in the PR meta line to copy the PR's URL
- Adds a "Copy" action to each comment's action row that copies the comment as Markdown (plus file path and permalink for diff comments)
- Sticky editor toolbar when writing/editing long descriptions or comments

## Requirements

### Userstyles

For installing userstyles I recommend using Stylus:

- Chrome: https://chrome.google.com/webstore/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne
- Firefox: https://addons.mozilla.org/en-US/firefox/addon/styl-us/

### Userscripts

For installing userscripts I recommend using Violentmonkey (or Tampermonkey):

- Chrome: https://chrome.google.com/webstore/detail/violentmonkey/jinjaccalgkegednnccohejagnlnfdag?hl=en
- Firefox: https://addons.mozilla.org/en-US/firefox/addon/violentmonkey/
